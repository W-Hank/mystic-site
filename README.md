# Mystic · 塔罗与星盘

纯静态站点。**无后端、无接口、无数据库、无埋点、无账号。**

## 部署（三选一，都不用命令行）

### 最快：Netlify Drop
1. 打开 https://app.netlify.com/drop
2. 把整个 `dist` 文件夹拖进去
3. 十秒后得到一个 `xxx.netlify.app` 网址，可以直接分享

免费额度：每月 100GB 流量。这个站总共 90KB，够用很久。

### Cloudflare Pages
1. https://dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets
2. 拖入 `dist` 文件夹
3. 得到 `xxx.pages.dev` 网址

### GitHub Pages
1. 新建仓库，把 `dist` 里的内容推到根目录
2. Settings → Pages → Source 选 main 分支根目录
3. 得到 `用户名.github.io/仓库名`

## 五个页面

**塔罗** — 78 张全牌库。输入问题，自动匹配牌阵，洗牌后自己点选，出解读。
解读按真实读牌法组合：问题分域、牌位语义、同花色归组、元素相冲、大牌连号、张力检测、按花色推时机。不是预生成的模板句。

**星盘** — 太阳、月亮、水星、金星、火星、木星、土星 + 上升 + 主要相位，SVG 轮盘。
可以不填出生时间（则不排上升，并提示月亮可能跨星座）。

**今日** — 无需任何输入，打开就是实时结果。六个周期：昨日 / 今日 / 明日 / 本周 / 本月 / 今年。
十二星座 × 综合、爱情、事业、学业、财运、健康。选自己的星座后出现七天走势图和每日记录。

**黄历** — 2024–2035 全量：农历、日干支、值神（黄道黑道）、建除十二神、冲煞、彭祖百忌、节气，以及二十项常用宜忌。

**易经** — 三枚铜钱掷六次起卦，本卦 / 变卦，按朱熹《周易本义》变爻法取用。六十四卦卦辞与三百八十六爻爻辞为公有领域原文，另附六十四卦的白话大意（本站整理）。

**合参** — 同一件事，塔罗 / 易 / 天象各看一眼。三面不必一致，它们答的不是同一个问题。

## 周期怎么算的

| 周期 | 采样 | 权重侧重 |
|---|---|---|
| 昨日·今日·明日 | 该日正午 1 点 | 全部星体 |
| 本周 | 周一到周日，7 个点 | 月亮降权，木土升权 |
| 本月 | 每 5 天一点 | 木星土星 1.1 |
| 今年 | 12 个月中点 | 木星土星 1.5，月亮权重 0 |

太阳星座当第一宫，整宫制。域对应宫位：
爱情 5·7 / 事业 10·6 / 学业 9·3 / 财运 2·8 / 健康 6·1。

## 存图

每个页面的右上区域都有「存图」按钮，点击后把当前结果绘成一张 1080 宽的竖版 PNG 并下载。
Canvas 手绘，不依赖任何截图库，离线可用；支持 Web Share 的设备上会优先调用系统分享。

## 依据

每个页面底部都有一段小字，写明该页内容的来源：

- **塔罗** — Waite《The Pictorial Key to the Tarot》(1911)、Pollack《Seventy-Eight Degrees of Wisdom》(1980)、Greer《Tarot for Your Self》(1984)
- **星盘** — JPL 近似开普勒根数、Meeus《Astronomical Algorithms》、Lilly《Christian Astrology》(1647)、Tompkins《Aspects in Astrology》
- **今日** — 太阳星座作第一宫、整宫制；周期采样与加权为本站设定，无传统依据
- **黄历** — cnlunar 生成 2024–2035 共 4383 天；宜忌取通行通书体例
- **易经** — 公有领域《周易》原文，维基文库与公开数据集交叉核对；变爻法依朱熹《周易本义》；白话为本站整理
- **合参** — 三套系统各自的依据见对应页面，不构成互相印证

## 数据说明

- 行星位置：JPL 近似开普勒根数（1800–2050），已做 J2000 → 当日黄道岁差修正
- 月球：Meeus 简化级数
- 精度对 pyephem 校验：太阳 0.007°、月球 0.157°、行星 < 0.13°
- 日柱干支：以 2026-11-07 = 乙酉 为锚点
